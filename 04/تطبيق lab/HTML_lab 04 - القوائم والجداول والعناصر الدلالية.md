# التمرين 1 — القوائم (Lists) ⏱️ 20 دقيقة

## 1.1 القائمة غير المرتبة `<ul>`

**المطلوب:** أنشئ قائمة بعنوان «مهاراتي» تحتوي على 4 مهارات بدون ترتيب.

**خطوات:**
1. أضف عنوانًا `<h2>مهاراتي</h2>`.
2. أنشئ قائمة `<ul>` بها 4 عناصر `<li>`.

<details>
<summary>💡 تلميح</summary>

كل عنصر في القائمة يوضع داخل `<li> ... </li>`، وكلها داخل `<ul> ... </ul>`.
</details>

<details>
<summary>✅ الحل</summary>

```html
<h2>مهاراتي</h2>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
  <li>حل المشكلات</li>
</ul>
```
</details>

## 1.2 القائمة المرتبة `<ol>`

**المطلوب:** أنشئ قائمة **مرتّبة** بعنوان «خطوات إنشاء صفحة ويب» بها 4 خطوات بالترتيب.

<details>
<summary>✅ الحل</summary>

```html
<h2>خطوات إنشاء صفحة ويب</h2>
<ol>
  <li>إنشاء ملف HTML</li>
  <li>كتابة هيكل الصفحة بالوسوم</li>
  <li>تنسيق الصفحة باستخدام CSS</li>
  <li>معاينة الصفحة في المتصفح</li>
</ol>
```
</details>

> ❓ **سؤال تفكير:** لماذا استخدمنا `ol` هنا و `ul` في التمرين السابق؟

## 1.3 القائمة التعريفية `<dl>`

**المطلوب:** أنشئ قائمة تعريفية «معلوماتي» تعرض: الاسم، التخصص، المدينة — كل مصطلح مع وصفه.

<details>
<summary>💡 تلميح</summary>

`<dt>` للمصطلح (Term)، و `<dd>` للوصف (Description).
</details>

<details>
<summary>✅ الحل</summary>

```html
<h2>معلوماتي</h2>
<dl>
  <dt>الاسم</dt>
  <dd>محمد أحمد</dd>

  <dt>التخصص</dt>
  <dd>تطوير الويب</dd>

  <dt>المدينة</dt>
  <dd>الرياض</dd>
</dl>
```
</details>

# التمرين 2 — الجداول (Tables) ⏱️ 20 دقيقة

**المطلوب:** أنشئ جدول «الجدول الدراسي الأسبوعي» بثلاثة أعمدة: **اليوم / المادة / الوقت**، وبه صفّان على الأقل من البيانات.

**خطوات:**
1. ابدأ بـ `<table border="1">`.
2. أنشئ صف الترويسة باستخدام `<th>` للعناوين.
3. أضف صفوف البيانات باستخدام `<td>`.

<details>
<summary>💡 تلميح</summary>

- كل صف = `<tr> ... </tr>`
- خلية عنوان = `<th>` (تظهر عريضة تلقائيًّا)
- خلية بيانات = `<td>`
</details>

<details>
<summary>✅ الحل</summary>

```html
<h2>الجدول الدراسي الأسبوعي</h2>
<table border="1">
  <tr>
    <th>اليوم</th>
    <th>المادة</th>
    <th>الوقت</th>
  </tr>
  <tr>
    <td>الأحد</td>
    <td>مبادئ برمجة الويب</td>
    <td>8:00 - 10:00</td>
  </tr>
  <tr>
    <td>الثلاثاء</td>
    <td>قواعد البيانات</td>
    <td>10:00 - 12:00</td>
  </tr>
</table>
```
</details>

> 🏆 **تحدٍّ إضافي (اختياري):** أضف صفًّا ثالثًا من عندك، ولاحظ الفرق في الشكل بين خلايا `th` و `td`.

# التمرين 3 — العناصر الدلالية (Semantic) ⏱️ 20 دقيقة

**المطلوب:** أعد بناء صفحة بسيطة باستخدام **العناصر الدلالية** بدلًا من `div` العادية.

**البنية المطلوبة:**
- `<header>` يحوي عنوان الموقع.
- `<nav>` يحوي 3 روابط تنقّل.
- `<section>` يحوي مقالًا `<article>`.
- `<footer>` يحوي حقوق النشر.

<details>
<summary>✅ الحل</summary>

```html
<header>
  <h1>مدوّنتي الشخصية</h1>
</header>

<nav>
  <a href="#home">الرئيسية</a> |
  <a href="#posts">المقالات</a> |
  <a href="#contact">تواصل معنا</a>
</nav>

<section>
  <article>
    <h2>أول مقال لي</h2>
    <p>هذه أول تدوينة أكتبها باستخدام العناصر الدلالية في HTML.</p>
  </article>
</section>

<footer>
  <p>© 2026 جميع الحقوق محفوظة</p>
</footer>
```
</details>

> ❓ **سؤال تفكير:** ما الفائدة من استخدام `<nav>` بدلًا من `<div>` عادية لروابط التنقّل؟
> (تلميح: فكّر في محرّكات البحث SEO وقارئات الشاشة Accessibility.)

# 🚀 المشروع الختامي — «صفحتي الشخصية» ⏱️ 30 دقيقة

اجمع **كل المهارات** في صفحة واحدة متكاملة تُعرّف بنفسك.

## 📌 المتطلبات (يجب أن تحتوي الصفحة على):

| # | المتطلب | المهارة |
|---|---------|---------|
| 1 | `<header>` فيه اسمك كعنوان `<h1>` | العناصر الدلالية |
| 2 | `<nav>` فيه روابط: نبذة، مهارات، دورات، تواصل | العناصر الدلالية |
| 3 | قسم «نبذة عني» بقائمة تعريفية `<dl>` (الاسم، التخصص، المدينة) | dl |
| 4 | قسم «مهاراتي» بقائمة غير مرتبة `<ul>` | ul |
| 5 | قسم «الدورات» بقائمة مرتبة `<ol>` | ol |
| 6 | قسم «جدول الخبرات» بجدول `<table>` (الجهة / الدور / المدة) | tables |
| 7 | `<aside>` فيه اقتباس أو معلومة جانبية | العناصر الدلالية |
| 8 | `<footer>` فيه بريدك الإلكتروني كرابط `mailto:` | العناصر الدلالية |

## 🗂️ الهيكل المقترح (اكمل الفراغات بنفسك):

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الشخصية</title>
</head>
<body>

  <header>
    <h1><!-- اسمك هنا --></h1>
  </header>

  <nav>
    <a href="#about">نبذة</a> |
    <a href="#skills">مهارات</a> |
    <a href="#courses">دورات</a> |
    <a href="#contact">تواصل</a>
  </nav>

  <section id="about">
    <h2>نبذة عني</h2>
    <dl>
      <!-- الاسم / التخصص / المدينة -->
    </dl>
  </section>

  <section id="skills">
    <h2>مهاراتي</h2>
    <ul>
      <!-- 4 مهارات -->
    </ul>
  </section>

  <section id="courses">
    <h2>الدورات</h2>
    <ol>
      <!-- 3 دورات بالترتيب -->
    </ol>
  </section>

  <section id="experience">
    <h2>جدول الخبرات</h2>
    <table border="1">
      <!-- ترويسة: الجهة / الدور / المدة + صفّان بيانات -->
    </table>
  </section>

  <aside>
    <p>💡 "التعلّم رحلة لا تنتهي."</p>
  </aside>

  <footer id="contact">
    <p>راسلني: <a href="mailto:me@example.com">me@example.com</a></p>
  </footer>

</body>
</html>
```
