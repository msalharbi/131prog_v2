# الأسبوع الأول – المحاضرة النظرية
## مقدمة حول الويب وتطوير المواقع

### أهداف التعلم
بنهاية المحاضرة يُتوقع أن يكون المتدرب قادرًا على:
1. التعرف على المجالات والأدوار الأساسية في تطوير الويب.
2. التمييز بين **Front-End** و **Back-End**.
3. توضيح دور HTML وCSS وJavaScript.
4. التمييز بين الإنترنت والويب.
5. شرح نموذج **Client / Server** بصورة مبسطة.
6. التعرف على مكونات **URL** ودور `index.html`.
7. تكوين تصور أولي عن دور أدوات AI Coding في تطوير الويب الحديث.

---

## 1. من أين نبدأ؟
أفضل نقطة بداية هي فهم **كيف يعمل الويب وكيف تُبنى صفحات الويب**. قد يبدأ المتدرب بموقع شخصي بسيط ثم ينتقل تدريجيًا إلى مشاريع أكبر. في هذا المقرر سنركز على الواجهة الأمامية باستخدام:

```text
HTML + CSS + JavaScript
```

## 2. الأدوار الرئيسية في تطوير المواقع
- **Design:** تجربة المستخدم UX، تصميم التفاعل IxD، وتصميم الواجهة UI.
- **Development:** بناء الموقع وكتابة الكود وإضافة الوظائف.
- **Content Strategy:** كتابة المحتوى وتنظيمه وإدارته.
- **Multimedia:** الصور والصوت والفيديو والرسوم المتحركة والعناصر التفاعلية.

في المشاريع الصغيرة قد يقوم شخص واحد بعدة أدوار، بينما تتوزع المسؤوليات في المشاريع الكبيرة بين متخصصين.

## 3. Front-End وBack-End
### Front-End
الجزء الذي يظهر للمستخدم ويتفاعل معه داخل المتصفح، ويشمل بناء الهيكل والتنسيق والتفاعل باستخدام HTML وCSS وJavaScript.

### Back-End
الجزء الذي يعمل على الخادم خلف الكواليس، ويشمل معالجة البيانات وقواعد البيانات والنماذج وإدارة المحتوى. قد يستخدم PHP أو Python أو Java وغيرها.

> **نطاق المقرر:** التركيز الأساسي على Front-End Development.

## 4. الطبقات الثلاث لصفحة الويب
| الطبقة | التقنية | الوظيفة |
|---|---|---|
| الهيكل والمحتوى | HTML | تحديد عناصر ومحتوى الصفحة |
| العرض والمظهر | CSS | التصميم والتنسيق |
| السلوك والتفاعل | JavaScript | إضافة التفاعل والمنطق |

```text
HTML       → Structure
CSS        → Presentation
JavaScript → Behavior
```

## 5. الإنترنت والويب
**الإنترنت Internet:** شبكة عالمية من الأجهزة المتصلة لتبادل البيانات وفق بروتوكولات.

**الويب World Wide Web:** إحدى الخدمات التي تعمل عبر الإنترنت، وتعتمد على المستندات والروابط التشعبية وبروتوكولات مثل HTTP وHTTPS.

> الإنترنت هو البنية التحتية، والويب إحدى الخدمات التي تعمل فوقها.

## 6. نموذج Client / Server
عند زيارة صفحة ويب:

```text
المستخدم يكتب URL
      ↓
Browser يرسل Request
      ↓
Web Server يستقبل الطلب
      ↓
Server يعيد Response
      ↓
Browser يعرض الصفحة
```

قد تتضمن الاستجابة HTML وCSS وJavaScript والصور.

## 7. عنوان الصفحة URL
**URL — Uniform Resource Locator** هو عنوان صفحة أو مورد على الويب.

```text
https://www.example.com/images/photo.jpg
   ↓            ↓              ↓
Protocol      Domain          Path
```

- **Protocol:** مثل HTTP أو HTTPS.
- **Domain:** اسم الموقع أو النطاق.
- **Path:** موقع المورد داخل الموقع.

## 8. لماذا index.html؟
عندما يطلب المستخدم مجلدًا دون اسم ملف، يبحث خادم الويب عادةً عن ملف افتراضي، ومن أشهر أسمائه `index.html`. لذلك سنستخدمه غالبًا كصفحة رئيسية للمشروع.

## 9. تطوير الويب في عصر الذكاء الاصطناعي
تستطيع أدوات AI Coding المساعدة في إنشاء وشرح ومراجعة وتصحيح وتحسين الكود، لكنها لا تلغي الحاجة إلى فهم الأساسيات.

سنستخدم دورة العمل:

```text
Understand → Build → Ask AI → Inspect → Test → Debug → Improve
```

وسيكون لدينا نوعان من الأنشطة:
- **AI OFF:** لبناء وفحص الفهم الأساسي.
- **AI ON:** لاستخدام أدوات AI في الإنشاء أو التعديل أو المراجعة، مع مسؤولية المتدرب عن التحقق من الناتج.
