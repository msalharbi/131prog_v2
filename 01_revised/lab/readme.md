# الأسبوع الأول – المعمل
## إعداد بيئة العمل واستكشاف الويب وإنشاء أول صفحة

### أهداف المعمل
بنهاية المعمل يُتوقع أن يكون المتدرب قادرًا على:
1. تجهيز بيئة تطوير الويب.
2. التعرف عمليًا على URL ومكوناته.
3. استخدام Developer Tools بصورة أولية.
4. إنشاء وتشغيل ملف `index.html`.
5. تعديل الصفحة وملاحظة أثر التغييرات.
6. تجهيز حساب GitHub للاستخدام التدريجي.

> **AI OFF:** الهدف هذا الأسبوع فهم البيئة الأساسية وكتابة أول ملف يدويًا.

## الأدوات المطلوبة
- Visual Studio Code
- متصفح حديث
- حساب GitHub

## النشاط 1: استكشاف URL
افتح موقعًا تعرفه وحدد Protocol وDomain وPath إن وجد.

```text
https://www.example.com/images/photo.jpg
Protocol → https
Domain   → www.example.com
Path     → /images/photo.jpg
```

## النشاط 2: Developer Tools
1. افتح صفحة ويب.
2. اضغط بزر الفأرة الأيمن على عنصر واختر **Inspect**.
3. افتح **Elements**.
4. حاول العثور على أحد عناصر HTML.

الهدف هو ملاحظة أن الصفحة المرئية مبنية من عناصر يمكن فحصها.

## النشاط 3: إعداد المشروع
أنشئ مجلدًا باسم `week01` وافتحه في VS Code، ثم أنشئ:

```text
week01/
└── index.html
```

## النشاط 4: أول صفحة HTML
اكتب الكود التالي بنفسك:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
</head>
<body>
    <h1>مبادئ برمجة صفحات الإنترنت</h1>
    <h2>صفحتي الأولى</h2>
    <p>مرحبًا، هذه أول صفحة ويب أقوم بإنشائها.</p>
</body>
</html>
```

احفظ الملف وافتحه في المتصفح.

## النشاط 5: Observe → Modify → Test
عد إلى VS Code:
1. غيّر `<h2>` إلى اسمك.
2. أضف تخصصك في فقرة.
3. أضف فقرة عن هدفك من المقرر.
4. احفظ الملف وحدّث المتصفح.

```text
Edit → Save → Refresh → Observe
```

## النشاط 6: لماذا index.html؟
غيّر اسم الملف مؤقتًا إلى `mypage.html` وافتحه مباشرة، ثم أعده إلى `index.html`. سنشرح لاحقًا لماذا تستخدم الخوادم `index.html` عادةً كملف افتراضي.

## النشاط 7: فحص صفحتك
باستخدام Inspect ابحث عن `<h1>` و`<h2>` و`<p>` وقارن العناصر بما كتبته في VS Code.

## النشاط 8: GitHub Setup
1. سجل الدخول إلى GitHub.
2. تأكد من بريدك الإلكتروني.
3. تعرف على مفهوم **Repository**.
4. احتفظ باسم المستخدم الخاص بك.

> لا يُطلب إتقان Git أو أوامر الرفع في الأسبوع الأول؛ سيتم إدخالها تدريجيًا.

```text
week01/
└── index.html
```
