# مقرر مبادئ برمجة صفحات الإنترنت

### وصف المقرر:
يقدم هذا المقرر المهارات الأساسية اللازمة لفهم وبناء وتطوير صفحات الويب باستخدام HTML وCSS وJavaScript، مع التركيز على فهم بنية الصفحة، تنسيق المحتوى، إنشاء النماذج، تصميم التخطيطات المتجاوبة، وإضافة التفاعل باستخدام JavaScript وDOM.

كما يدمج المقرر بصورة تدريجية مهارات **التطوير بمساعدة الذكاء الاصطناعي (AI-Assisted Web Development)**، بحيث يتعلم المتدرب كيفية تحويل المتطلبات إلى تعليمات واضحة، والاستفادة من أدوات الذكاء الاصطناعي في إنشاء الكود أو تعديله، ثم قراءة المخرجات وفهمها واختبارها ومراجعتها وتصحيحها وتحسينها. لا يهدف المقرر إلى استبدال تعلم HTML وCSS وJavaScript، وإنما إلى تمكين المتدرب من استخدامها بفاعلية ضمن بيئة تطوير حديثة تعتمد على التعاون بين المطور وأدوات الذكاء الاصطناعي.

> **فلسفة المقرر:** Learn → Build → Ask AI → Inspect → Test → Debug → Improve

## **أهداف المقرر**

بنهاية المقرر يتوقع أن يكون المتدرب قادرًا على:

1. التعرف على المفاهيم الأساسية لتطوير صفحات الويب وكيفية عملها.
2. إنشاء وتعديل صفحات الويب باستخدام HTML وCSS وJavaScript.
3. قراءة وفهم وتفسير كود صفحات الويب بدلاً من الاعتماد على حفظ الصياغة فقط.
4. إنشاء نماذج ويب والتحقق من صحة البيانات المدخلة.
5. تطوير واجهات ويب تفاعلية ومتجاوبة مع أحجام الشاشات المختلفة.
6. استخدام أدوات الذكاء الاصطناعي المساعدة في تطوير صفحات الويب بصورة فعالة ومسؤولة.
7. تحويل متطلبات المستخدم إلى تعليمات واضحة ومحددة لأدوات AI Coding.
8. مراجعة وتقييم وتصحيح الكود المولد بواسطة الذكاء الاصطناعي.
9. اختبار الحلول المولدة بالذكاء الاصطناعي والتحقق من مطابقتها للمتطلبات.
10. تحسين وإعادة تنظيم (Refactor) الكود مع المحافظة على الوظائف والتصميم المطلوب.

## **آلية التقييم في الأنشطة المدعومة بالذكاء الاصطناعي**

لا يتم تقييم المتدرب على الحصول على كود يعمل فقط، وإنما على عملية التطوير كاملة، وتشمل حسب طبيعة النشاط:

- تحديد وفهم المتطلبات.
- صياغة Prompt واضح ومحدد.
- قراءة وفهم الكود الناتج.
- اكتشاف الأخطاء أو الأجزاء غير المناسبة.
- تعديل الكود يدويًا عند الحاجة.
- اختبار النتيجة والتحقق من مطابقتها للمتطلبات.
- توضيح ما تم قبوله أو رفضه من اقتراحات أداة الذكاء الاصطناعي وسبب ذلك.

---

## **سياسة استخدام الذكاء الاصطناعي في المقرر**

يتم تحديد حالة استخدام الذكاء الاصطناعي بوضوح في كل نشاط:

- **AI OFF:** يجب تنفيذ النشاط دون استخدام أدوات توليد الكود، بهدف قياس فهم الأساسيات والقدرة على كتابة وقراءة الكود.
- **AI ON:** يسمح أو يُطلب استخدام أداة ذكاء اصطناعي، مع بقاء المتدرب مسؤولًا عن فهم الكود الناتج وصحته ومطابقته للمتطلبات.

لا يعتبر الكود المولد بواسطة الذكاء الاصطناعي صحيحًا تلقائيًا، ويجب على المتدرب مراجعته واختباره قبل اعتماده.

## **ملاحظات مهمة**

- الالتزام بالمواعيد النهائية لتسليم الواجبات والمشاريع.
- ضرورة الحضور والمشاركة في الأنشطة العملية والنقاشات المتعلقة بمراجعة الكود.

- المتدرب مسؤول عن فهم أي كود يقوم بتسليمه حتى لو تم إنشاؤه أو تعديله باستخدام الذكاء الاصطناعي.

- يتم تحديث الموارد والدروس بشكل دوري عبر GitHub repository الخاص بالمقرر.
