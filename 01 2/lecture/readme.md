# الأسبوع الأول – المحاضرة النظرية
## مقدمة حول الويب وكيف تعمل المواقع الإلكترونية

### أهداف المحاضرة
بنهاية المحاضرة يُتوقع أن يكون المتدرب قادرًا على:
1. التمييز بين الإنترنت والويب.
2. فهم آلية عمل صفحات الويب بصورة مبسطة.
3. التعرف على المتصفح وخادم الويب.
4. فهم دور HTML وCSS وJavaScript في الواجهة الأمامية.
5. التعرف على أدوات المقرر: VS Code وBrowser DevTools وGit وGitHub.
6. فهم دور أدوات الذكاء الاصطناعي المساعدة في تطوير الويب.

---

## 1. الإنترنت والويب

**الإنترنت Internet:** شبكة عالمية تربط الأجهزة والخوادم وتسمح بتبادل البيانات.

**الويب World Wide Web:** خدمة تعمل عبر الإنترنت وتتيح الوصول إلى صفحات ومواقع الويب باستخدام المتصفح.

> الإنترنت هو البنية التحتية للاتصال، بينما الويب إحدى الخدمات التي تعمل عبرها.

---

## 2. كيف تعمل صفحة الويب؟

عند كتابة عنوان موقع في المتصفح تحدث العملية بصورة مبسطة كالتالي:

1. يرسل المتصفح طلبًا إلى خادم الويب.
2. يستقبل الخادم الطلب.
3. يرسل ملفات الصفحة.
4. يقرأ المتصفح HTML وCSS وJavaScript.
5. يعرض الصفحة للمستخدم.

```text
User → Browser → Request → Web Server
                         ↓
               HTML + CSS + JavaScript
                         ↓
                       Browser
```

---

## 3. المتصفح Browser

المتصفح هو البرنامج المستخدم لفتح صفحات الويب وعرضها، مثل:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

---

## 4. تقنيات Front-End الأساسية

### HTML
تحدد **هيكل ومحتوى الصفحة** مثل العناوين والفقرات والصور والروابط والجداول والنماذج.

### CSS
تتحكم في **الشكل والتنسيق** مثل الألوان والخطوط والمسافات والتخطيط والتصميم المتجاوب.

### JavaScript
تضيف **السلوك والتفاعل** مثل الاستجابة للأحداث والتحقق من البيانات وتعديل محتوى الصفحة.

```text
HTML       → Structure
CSS        → Presentation
JavaScript → Behavior
```

---

## 5. أدوات المقرر

- **Visual Studio Code:** كتابة وتحرير الكود.
- **Web Browser:** تشغيل واختبار الصفحات.
- **Developer Tools:** فحص الصفحات واكتشاف الأخطاء.
- **Git:** تتبع تغييرات المشروع.
- **GitHub:** استضافة المستودعات وإدارة مشاريع وأنشطة المقرر.

---

## 6. Git وGitHub

**Git** نظام لإدارة إصدارات الملفات وتتبع التغييرات.

**GitHub** منصة لاستضافة مستودعات Git ومشاركة وإدارة المشاريع البرمجية.

سيتم استخدام GitHub تدريجيًا خلال المقرر لحفظ ملفات الأنشطة والمشاريع.

---

## 7. تطوير الويب في عصر الذكاء الاصطناعي

يمكن لأدوات AI Coding المساعدة في إنشاء وشرح ومراجعة وتصحيح وتحسين الكود، لكن الهدف ليس مجرد الحصول على كود جاهز.

دورة العمل التي سنستخدمها:

```text
Understand → Build → Ask AI → Inspect → Test → Debug → Improve
```

لذلك سيحتوي المقرر على أنشطة **AI OFF** للتأكد من فهم الأساسيات، وأنشطة **AI ON** لتعلم الاستفادة الصحيحة من أدوات الذكاء الاصطناعي.

---

5. ما الفرق بصورة مبسطة بين Git وGitHub؟
