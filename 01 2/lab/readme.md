# الأسبوع الأول – المعمل
## إعداد بيئة تطوير الويب وإنشاء أول صفحة

### أهداف المعمل
بنهاية المعمل يُتوقع أن يكون المتدرب قادرًا على:
1. تجهيز بيئة تطوير الويب.
2. إنشاء مجلد مشروع منظم.
3. إنشاء ملف HTML باستخدام VS Code.
4. تشغيل الصفحة وتعديلها في المتصفح.
5. فتح Developer Tools.
6. التعرف مبدئيًا على GitHub.

> **AI OFF:** هذا النشاط تأسيسي ولا يحتاج إلى استخدام الذكاء الاصطناعي لإنشاء الكود.

---

## الأدوات المطلوبة

- Visual Studio Code
- متصفح حديث
- حساب GitHub

---

## 1. إنشاء المشروع

أنشئ مجلدًا باسم:

```text
week01
```

ثم أنشئ داخله:

```text
week01/
└── index.html
```

---

## 2. إنشاء أول صفحة

اكتب داخل `index.html`:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
</head>
<body>

    <h1>مرحبًا بكم في مقرر مبادئ برمجة صفحات الإنترنت</h1>
    <p>هذه أول صفحة ويب أقوم بإنشائها.</p>

</body>
</html>
```

احفظ الملف ثم افتحه في المتصفح.

---

## 3. تعديل الصفحة

أضف:

```html
<h2>معلومات عني</h2>
<p>اسمي .......... وأدرس تخصص ..........</p>
<p>أتطلع في هذا المقرر إلى تعلم تطوير صفحات الويب.</p>
```

احفظ الملف ثم حدّث الصفحة في المتصفح ولاحظ التغيير.

---

## 4. Developer Tools

1. افتح الصفحة في المتصفح.
2. اضغط بزر الفأرة الأيمن على العنوان.
3. اختر **Inspect**.
4. ابحث عن العنصر `<h1>` داخل تبويب Elements.

الهدف هذا الأسبوع هو التعرف على الأداة فقط.

---

## 5. GitHub

1. سجّل الدخول إلى حساب GitHub.
2. تعرف على مفهوم **Repository**.
3. تأكد من إمكانية الدخول إلى حسابك.

إذا لم يكن لديك حساب، أنشئ حسابًا شخصيًا لاستخدامه في أنشطة المقرر.

> سيتم تعلم Git وGitHub تدريجيًا، ولا يُطلب إتقان أوامر Git في الأسبوع الأول.

---

# النشاط المطلوب

أنشئ صفحة شخصية بسيطة تحتوي على:

- عنوان رئيسي باسم المقرر.
- اسمك.
- تخصصك.
- فقرة عن هدفك من تعلم تطوير الويب.
- عنوان فرعي بالنص `My First Web Page`.

### التسليم

```text
week01/
└── index.html
```

---

## تحقق من عملك

تأكد من أنك تستطيع:
- فتح المشروع في VS Code.
- إنشاء وحفظ `index.html`.
- تشغيل الصفحة في المتصفح.
- تعديل النص ومشاهدة النتيجة.
- فتح Developer Tools.
- الدخول إلى GitHub.

---

## تحدي إضافي

حاول إضافة:
- عنوان باستخدام `<h3>`.
- فقرة باستخدام `<p>`.
- خط أفقي باستخدام `<hr>`.

---

## الأسبوع القادم

سنبدأ دراسة **HTML** بصورة منهجية: الهيكل الأساسي، الوسوم الأساسية، والعناصر الدلالية.
