# تمرين تقييم — المحاضرة 5

## نموذج تقييم

> **المقرر:** مبادئ برمجة صفحات الويب
> **المحاضرة المرجعية:** HTML_lec 05 (النماذج)
> **الدرجة:** درجتان (2)
> **التسليم:** ملف `feedback.html`

> **ملاحظة:** التمرين بـ HTML فقط — بدون CSS. المطلوب صحّة البنية لا التنسيق، وأن يظهر كل عنصر في سطر مستقل.

---

## المطلوب

أنشئ صفحة ويب باسم `feedback.html` فيها نموذج تقييم يحتوي العناصر التالية:

1. حقل لكتابة **الاسم**.
2. سؤال **«تقييمك للدورة»** يُسمح فيه باختيار **خيار واحد فقط** من: ممتاز / جيد / ضعيف.
3. سؤال **«ما الذي أعجبك؟»** يُسمح فيه باختيار **أكثر من خيار** من: المحتوى / المدرّب / التمارين.
4. حقل لكتابة **الملاحظات** (نص يتّسع لعدة أسطر).
5. **زر لإرسال** النموذج.
6. **تسمية واضحة** لكل حقل، ترتبط به.
